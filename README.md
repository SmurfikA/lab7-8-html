# MyPortfolio - Мінісайт на JavaScript

Це демонстраційний багатосторінковий мінісайт, який реалізує всі обов'язкові завдання практичної роботи №7-8 з теми "Додавання JavaScript до готового HTML/CSS-мінісайту".

## Структура проекту

```
lab7-8-html/
├── index.html              # Головна сторінка
├── pages/
│   ├── about.html         # Сторінка "Про мене" з вкладками та навичками
│   └── contact.html       # Сторінка контакту з формою
├── assets/
│   ├── img/               # Папка для зображень
│   └── media/             # Папка для медіа-файлів
├── styles/
│   └── style.css          # Єдиний CSS файл з усіма стилями
├── js/
│   ├── main.js            # Основний файл з базовою функціональністю
│   └── contact.js         # Логіка для обробки форми контакту
├── data/
│   └── services.json      # JSON-дані для прикладу
└── README.md              # Цей файл
```

## Реалізовані функції

### 1. Підключення JavaScript і стартова структура файлів
- JavaScript підключений через `<script src="..." defer></script>`
- Код організований у окремі функції ініціалізації
- Перевірка існування елементів перед роботою
### 2. Підсвічування активної сторінки в навігації
- Функція `initActiveNav()` визначає поточну сторінку
- Активна сторінка отримує клас `.is-active`
- Робить на всіх сторінках без дублювання
### 3. Мобільне меню
- Кнопка-бургер з'являється на малих екранах
- Меню розгортається/згортається при кліку
- Автоматичне закриття після вибору пункту
### 4. Перемикач світлої/темної теми
- Кнопка для зміни теми на `<body>`
- Обраний режим зберігається в `localStorage`
- Тема відновлюється при перезавантаженні сторінки
### 5. Кнопка "Вгору" та динамічний рік у footer
- Кнопка з'являється при прокручуванні вниз
- Плавне прокручування вгору при кліку
- Поточний рік автоматично підставляється у footer
### 6. Акордеон для структурованого контенту
- На головній сторінці "Послуги" реалізовані як акордеон
- Розгортання/згортання при кліку
- Одночасно може бути відкритою лише одна секція
### 7. Фільтрація контенту
- На головній сторінці портфоліо з фільтрацією за категоріями
- Фільтри: Усі, Веб, Дизайн, Мобіль
- Схований елемент не залишає проміжків у макеті
### 8. Модальні вікна
- Модальні вікна для кожної картки портфоліо
- Відкриваються по кліку на кнопку "Деталі"
- Закриваються по кнопці X, на overlay або ESC
### 9. Валідація форми та лічильник символів
- Перевірка: ім'я (мінімум 2 символи), email (формат), повідомлення (не пусте)
- Зрозумілі повідомлення про помилки під полями
- Лічильник символів для textarea (максимум 500)
### 10. Збереження чернетки та обробка submit
- Автоматичне збереження чернетки в `localStorage`
- Відновлення даних при перезавантаженні сторінки
- Модальне вікно з підтвердженням очищення
- Успішна "відправка" показується в модальному вікні

## Як запустити

1. **Відкрити у браузері:**
   - Просто відкрити `index.html` у браузері
   - Або використати Live Server розширення у VS Code

2. **Клавіш Shift+Alt+S** у VS Code для запуску Live Server

3. **Командний рядок (Python):**
   ```bash
   python -m http.server 8000
   # Потім відкрити http://localhost:8000
   ```

## Особливості дизайну

- **Адаптивна верстка:** мобільна, планшет, десктоп
- **Темна/світла тема:** з збереженням вибору
- **Плавні переходи:** анімації та transitions
- **CSS Grid/Flexbox:** сучасна верстка
- **Семантичний HTML:** доступність та SEO

| `contactDraft` | Чернетка форми контакту |

## Технологічні стек

- **HTML5** - семантична верстка
